# 角色设定
你是一位资深的全栈开发工程师，精通前端开发与后端架构。现在需要你帮我从零开发一个名为“酷点无畏契约点位库”的网站。这是一个面向游戏《无畏契约》玩家的非盈利素材与点位分享平台。

# 技术栈要求
- 前端：[请填写你想要的技术，例如：Vue3 + Element Plus 或 React + Tailwind CSS]
- 后端：[请填写你想要的技术，例如：Node.js (Express/NestJS) 或 Python (Django/FastAPI)]
- 数据库：[请填写，例如：MySQL 或 MongoDB]

# 项目说明
本站为AI工具生产的非盈利素材站点，与游戏厂商无任何关联，所有内容版权归对应官方所有，仅供学习参考，禁止用于商业用途。

# 核心功能需求
请实现以下前端（用户端）和后端（管理端）功能模块：

## 1. 前台用户端
- **顶部导航栏**：包含 Logo，以及“地图”、“特工”、“阵营”、“点位”、“公告”五个主菜单。如果是管理员登录，需显示“管理”入口。
- **点位浏览与筛选**：
  - 核心页面，展示所有玩家上传的点位。
  - 支持按“地图”、“特工”、“阵营”三个维度进行联动筛选。
  - 每个点位卡片需展示：上传者、点位标题、[图片/视频预览]、点赞数、评论数。
  - 点击可查看点位详情页。
- **用户互动与共创**：
  - 用户可注册、登录。
  - 登录后可对喜欢的点位“点赞”。
  - 提供“上传点位”功能，用户可填写点位描述并上传[图片/视频链接]。
- **评论区（类似抖音模式）**：
  - 在点位详情页底部展示评论区。
  - 支持发表评论，并支持对他人的评论进行“回复”（支持二级嵌套回复结构）。
  - 权限控制：用户可以删除自己发表的评论及回复；管理员有权限删除任何用户的评论或回复。
  - 删除评论时，如果有子回复，需做合理处理（如标记“该评论已删除”保留占位，或级联删除，请给出你认为最合理的方案并说明理由）。
- **贡献榜模块**：
  - 展示对网站有贡献的玩家。
  - 排序维度：按“上传数量”排序、按“获赞数量”排序。
  - 文案：“由衷感谢所有为本站贡献力量的玩家们！”
- **免责声明弹窗**：
  - 首次访问网站时强制弹出模态框。
  - 内容：“免责声明：本站为AI工具生产的非盈利素材站点，与游戏厂商无任何关联，所有内容版权归对应官方所有，仅供学习参考，禁止用于商业用途。”
  - 需点击“OK”或“✕”关闭后才能浏览网页。

## 2. 后台管理端
- **管理总台仪表盘**：展示站点基础数据统计（总点位数、总用户数、今日新增等）。
- **基础数据管理**：
  - 管理地图：对游戏地图进行增删改查。
  - 管理特工：对特工信息进行增删改查（含特工所属阵营）。
- **内容与公告管理**：
  - 公告管理：发布、编辑、删除前台展示的公告。
- **用户与社区管理**：
  - 管理用户：查看所有用户信息，支持禁用违规账号。
  - 举报处理：处理用户对劣质/违规点位的举报，支持驳回或直接删除点位。
  - 处理历史：查看所有已处理的举报记录及处理结果。
  - 评论管理：提供评论列表，管理员可搜索、查看所有点位的评论，并具有删除任意违规评论的权限。
- **数据维护**：
  - 导出数据：支持将点位、用户等数据导出为 CSV/Excel 格式。
  - 导入数据：支持上传 CSV/Excel 批量导入点位数据。

# 数据库设计要求（供参考）
请设计合理的数据库表结构，至少包含：
1. users (用户表：账号、密码、角色[普通用户/管理员]、上传数、获赞数)
2. maps (地图表：地图名、地图图片)
3. agents (特工表：特工名、所属阵营、技能介绍)
4. factions (阵营表：阵营名)
5. spots/locations (点位表：标题、上传用户ID、关联地图ID、关联特工ID、内容描述、媒体链接、点赞数、创建时间)
6. comments (评论表：关联点位ID、评论用户ID、父评论ID[用于回复嵌套]、回复目标用户ID、内容、创建时间、逻辑删除标记)
7. reports (举报表：举报人ID、被举报点位ID、举报原因、处理状态、处理人ID、处理时间)
8. announcements (公告表：标题、内容、发布时间)
