# 酷点·无畏契约点位库 — 部署与优化指南

## 一、部署指南

### 方式一：Vercel 部署（推荐）

#### 步骤 1：准备代码仓库

1. 在 GitHub 创建仓库
2. 将项目代码推送到仓库

```bash
git init
git add .
git commit -m "酷点无畏契约点位库"
git remote add origin https://github.com/你的用户名/valorant-spots.git
git push -u origin main
```

#### 步骤 2：Vercel 导入项目

1. 访问 https://vercel.com 并登录
2. 点击 "New Project"
3. 选择 GitHub 仓库并导入
4. Framework Preset 选择 "Next.js"
5. 点击 Deploy

#### 步骤 3：数据库持久化

Vercel 的文件系统是只读的，SQLite 文件无法持久化。推荐方案：

**方案 A：Vercel Postgres（免费 60 天试用）**
1. 在 Vercel Dashboard 点击 "Storage"
2. 创建 Postgres 数据库
3. 自动获得连接字符串
4. 修改 `prisma/schema.prisma`：
   ```prisma
   datasource db {
     provider = "postgresql"
     url      = env("DATABASE_URL")
   }
   ```
5. 运行 `npx prisma db push` 初始化表
6. 运行 `npx prisma db seed` 填充种子数据

**方案 B：Turso（SQLite 云服务，免费额度）**
1. 注册 https://turso.tech
2. 创建数据库，获取连接字符串
3. 安装 `@libsql/client`
4. 修改 Prisma datasource

#### 步骤 4：环境变量

在 Vercel 项目设置 → Environment Variables 中配置：

| 变量名 | 值 | 说明 |
|--------|-----|------|
| `DATABASE_URL` | `postgresql://...` | 数据库连接字符串 |
| `NEXTAUTH_SECRET` | 随机字符串 | 会话密钥（可选） |

### 方式二：自有服务器部署（VPS）

```bash
# 1. 克隆代码
git clone https://github.com/你的用户名/valorant-spots.git
cd valorant-spots

# 2. 安装依赖
npm install

# 3. 配置环境变量
echo 'DATABASE_URL=file:./db/custom.db' > .env

# 4. 初始化数据库
npx prisma db push
npx prisma db seed

# 5. 构建
npm run build

# 6. 启动（推荐用 PM2 守护）
npm install -g pm2
pm2 start npm --name "valorant-spots" -- start
pm2 save
pm2 startup

# 7. Nginx 反向代理（可选）
# 配置 proxy_pass http://localhost:3000
```

## 二、性能优化建议

### 1. 图片压缩和优化

- **上传时压缩**：使用 `sharp` 库在服务端自动压缩上传的图片
  ```bash
  npm install sharp
  ```
  在 `/api/upload` 中添加压缩逻辑

- **WebP 格式**：将上传的 PNG/JPG 自动转换为 WebP 格式，减少 30-50% 体积

- **CDN 加速**：部署后使用 Vercel 自带的 CDN，图片自动全球加速

### 2. 懒加载

- 已实现：点位列表和详情页的图片使用 `loading="lazy"` 属性
- 建议扩展：特工头像和地图图片也添加懒加载

### 3. 缓存策略

- **Prisma 查询缓存**：对不常变的数据（地图、特工列表）添加内存缓存
- **HTTP 缓存**：在 API 路由中添加 `Cache-Control` 头
  ```ts
  headers.set('Cache-Control', 'public, s-maxage=60, stale-while-revalidate=300')
  ```
- **React Query/SWR**：客户端数据请求使用 SWR 缓存，减少重复请求

### 4. 数据库索引

在 `schema.prisma` 中为常用查询字段添加索引：
```prisma
model Spot {
  // ... 已有字段
  @@index([mapId, agentId, faction, status])
  @@index([likeCount])
  @@index([creatorId])
}
```

## 四、安全优化

### 1. 输入验证（已实现）

使用 Zod schema 验证所有用户输入：
- `registerSchema` — 注册（昵称 0-6 字 + 密码 ≥6 位）
- `loginSchema` — 登录
- `createSpotSchema` — 创建点位
- `createCommentSchema` — 创建评论
- `likeSchema` — 点赞/点踩
- `reportSchema` — 举报

### 2. CSRF 防护（已实现）

- **双提交 Cookie 模式**：
  - 登录时生成 CSRF token，写入 Cookie
  - POST/PUT/DELETE 请求需在 Header 中携带 token
  - 服务端验证 Cookie 中的 token 与 Header 一致
- `withAuth/withAdmin/withSuperAdmin` 中间件自动校验

### 3. XSS 防护

- React 自动转义 JSX 中的内容
- `sanitizeHtml()` 函数可用于手动转义
- 图片路径只接受 `/uploads/` 开头的相对路径
- 评论内容通过 React 渲染，不会被解析为 HTML

### 4. 其他安全措施

- 密码哈希：SHA-256 + 每用户独立盐值
- Session：httpOnly + SameSite=Strict + 7 天过期
- 权限层级：管理员不能操作同级和上级
- 举报去重：24 小时内同一用户不能重复举报
- 审核记录：保留 24 小时，可追溯
